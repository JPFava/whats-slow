WHAT TO DO NEXT
------------------------------------------------------------------------
• Close tabs you are not using and turn off extensions you do not recognize.
  Then restart Chrome. If it is still this heavy with one window, the problem
  is an extension or a single site.

• Click the OneDrive cloud icon, choose Pause syncing, and see if the PC feels
  normal. If it does, a sync backlog was the cause.

• Save anything open in Microsoft Word if you can, then close it. A window
  Windows already calls 'not responding' usually will not recover on its own.

• Free space on the full drive. Aim for at least 15% free, then restart the
  PC.

• Back up files you cannot replace. Then check the drive's health, or have a
  shop do it. Disk errors are a hardware warning, not an app to uninstall.

This check itself was using about 80 MB of memory while it watched. That is
the cost of measuring, and it is not counted against your programs.

HOW TO JUDGE THIS REPORT
------------------------------------------------------------------------
• Run this while the PC actually feels slow. A check taken when everything
  feels fine will look fine.

• One pass is a snapshot. If a program is listed as slowing others, run again
  for 20 seconds, three times (see the instructions). High every time means a
  real load. High once means a spike, such as an update or a scan.

• Processor percent here is the share of the whole PC, not of one core. Task
  Manager often shows a bigger number for the same process because 100% there
  can mean a single core.

• A single Windows error is usually one crash. It does not, by itself, slow
  the rest of the PC. Several errors every minute can, when they come from a
  program other software waits on (file sync, search, File Explorer, security,
  updates).

• This check does not see which browser tab, and it does not see inside a
  program's private errors unless Windows wrote them to the event log.

• It does not measure internet speed. If the processor is mostly free and only
  websites feel slow, the network or the site is the problem.

• Nothing is closed or changed. You decide what to quit.

The impact number (out of 100) only ranks programs against each other. It is not a health grade and it is not a virus score. Read the sentences.
